# Simple Caesar Cipher 

The script encodes and decodes the text entered into the input. 

![input](/images/input.png)

To use it, enter the text, select a number between 1 and 25 for the shift, and finally choose whether to encrypt or decrypt.

Example:

![text](/images/text.png)

![shift](/images/shift.png)

![ask](/images/ask.png)


The shift determines how many positions each letter moves in the alphabet.
For instance, with a shift of 3, A becomes D, B becomes E, and C becomes F.
For decryption, the letters are shifted back by the same number of positions.


---

## Usage

1. Clone the repository:
    ```bash
    git clone https://github.com/d4vidlinux/simple-caesar-cipher.git
    cd simple-caesar-cipher
    ```

2. Install Python
    
    [Download Python](https://python.org/downloads)

3. Execute:
    ```bash
    python3 caesarcipher.py
    ```
